x64emu

An x86-64 CPU written in WebAssembly text format, with a VGA adapter, a virtual BIOS, and a JavaScript platform around it.
Boot a disk image (BIOS boot: ISO, floppy, or hard disk)
Images are read in pieces as the guest asks for them, so size is not limited by memory.
Memory hard drive (blank, writable, on ATA and INT 13h)
not attached
Or load a Linux kernel directly (no BIOS)
